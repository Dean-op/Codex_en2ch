# Codex 中文桥 V1 需求文档

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品暂定名 | Codex 中文桥 |
| 版本 | V1.0 |
| 目标平台 | Windows 10/11 |
| 支持对象 | Codex Desktop |
| 状态 | 已确认需求 |

## 2. 问题与目标

用户希望使用中文表达需求，但希望 Codex Desktop 实际收到英文提示词、产生英文回答，以获得更稳定的编程协作效果。现有翻译工具需要反复复制、切换和整理 Markdown，代码、公式、链接和命令也容易被误改。

Codex 中文桥是独立的桌面辅助工具，不修改、不注入 Codex Desktop。它通过悬浮输入窗、全局快捷键和剪贴板监听完成两条流程：

1. 用户在悬浮窗输入中文，工具忠实翻译成英文并粘贴到 Codex 的输入框。
2. 用户在 Codex 中点击回答的复制按钮，工具翻译剪贴板中的回答，并在独立悬浮窗中渲染中文结果。

V1 的目标是降低中英切换成本，严格保护技术内容，并让用户始终掌握发送与关闭窗口的最终控制权。

## 3. 产品原则

1. **忠实翻译优先。** 只转换语言，不优化、扩写、总结或改变任务要求。
2. **格式不能损坏。** 代码、公式、链接地址、路径、命令、配置和报错必须原样保留。
3. **不代替用户提交。** 英文提示词只粘贴到 Codex 输入框，绝不自动按 Enter 或发送。
4. **不读取会话数据。** 工具只处理用户主动输入的文本，以及用户复制到系统剪贴板的内容。
5. **默认不留痕。** 不保存提示词、回答、翻译历史或 API Key 明文。

## 4. 范围

### 4.1 V1 包含

- Windows 原生桌面应用。
- 仅识别和适配 Codex Desktop。
- 中文悬浮输入窗与英文回填。
- Codex 前台状态下的剪贴板监听与回答翻译。
- OpenAI 兼容的 Chat Completions 翻译接口。
- Markdown、GFM 表格、代码块、行内代码和 LaTeX 公式的渲染。
- 保留 Markdown 结构的分段翻译、校验与失败保护。
- API 地址、模型、快捷键和显示偏好的设置页。

### 4.2 V1 不包含

- Claude Code、Codex CLI、浏览器版 Codex 或其他应用的适配。
- 自动监听 Codex 新回答、OCR 或 UI 自动化抓取。
- 自动发送英文提示词。
- 提示词优化、重写、摘要或代理式任务拆分。
- 聊天历史、翻译历史、云端同步和团队共享术语表。
- 离线翻译模型。

## 5. 用户与使用场景

### 5.1 目标用户

主要用户是中文母语的软件开发者，日常在 Windows 上使用 Codex Desktop，能提供可用的 OpenAI 兼容 API 服务和模型。

### 5.2 中文输入到 Codex

1. 用户激活 Codex Desktop。
2. 用户按 `Ctrl+Alt+I`（可在设置中修改）打开中文输入悬浮窗。
3. 用户输入中文需求、上下文和必要的代码片段。
4. 用户按 `Ctrl+Enter` 或点击“翻译并粘贴”。
5. 工具将可翻译文本转成英文，恢复 Codex 窗口焦点并粘贴内容。
6. 用户在 Codex 中检查后自行发送。

### 5.3 Codex 回答到中文悬浮窗

1. 用户在 Codex Desktop 中点击一条回答的复制按钮。
2. 工具发现前台窗口仍是 Codex，且剪贴板存在新的可翻译文本。
3. 工具翻译文本并展示不抢焦点的置顶结果浮窗。
4. 用户阅读渲染后的中文、复制中文内容，或切换查看英文原文。

## 6. 功能需求

### FR-01 目标窗口识别

- 工具仅在当前前台窗口被识别为 Codex Desktop 时响应输入快捷键和自动翻译。
- 打开输入窗前，工具记录目标窗口句柄、进程标识和记录时间。
- 翻译完成时，若目标窗口不再有效，工具只将英文留在应用内并提示用户手动复制，不执行粘贴。
- 用户可在设置页重新选择或校验 Codex Desktop 的可执行程序特征，以应对安装路径或版本变化。

### FR-02 中文输入悬浮窗

- 输入窗必须轻量、置顶、可通过快捷键唤起或关闭。
- 输入区支持多行文本、粘贴和代码片段。
- `Ctrl+Enter` 等同于“翻译并粘贴”；`Esc` 关闭窗口并清空未提交内容。
- 翻译进行中显示状态并禁止重复提交；用户可取消尚未完成的请求。
- 翻译成功后，输入窗关闭，英文粘贴到已记录的 Codex 输入框。
- 工具不触发 Codex 的发送操作。

### FR-03 Codex 剪贴板回答翻译

- 当 Codex Desktop 位于前台且系统剪贴板出现新文本时，工具在短暂去抖后检查文本。
- 工具将“前台为 Codex 时复制的文本”视为待翻译内容；外部应用无法可靠地区分复制按钮和 `Ctrl+C`，两者均应支持。
- 文本不含可翻译自然语言、内容过短、与最近一次内容相同，或来自工具自身的剪贴板事务时，不显示结果窗。
- 翻译请求失败时，不显示不完整翻译；可在通知中提供重试入口。

### FR-04 结果悬浮窗

- 自动出现时，结果窗置顶但不抢走 Codex 的输入焦点。
- 窗口应支持移动、调整尺寸、固定、关闭和复制中文。
- 默认展示中文渲染结果；用户可以切换到英文原文。
- 支持 CommonMark、GFM 表格、任务列表、代码块、行内代码、行内公式和块级公式。
- 代码块必须保留原语言、缩进和字符内容，可复制。
- 结果窗不保存内容；关闭后立即从内存释放。

### FR-05 忠实翻译与格式保护

- V1 只提供“忠实翻译”模式。
- 任何代码围栏、行内代码、数学公式、链接目标、图片地址、文件路径、URL、命令、JSON/YAML、环境变量和堆栈输出必须逐字保留。
- 普通 Markdown 结构，包括标题、列表、引用、表格分隔符和强调标记，必须保持有效。
- 只有文本片段会发送至翻译模型；翻译模型不能看到敏感的受保护片段内容，除非该片段属于普通语言文本。
- 重组前必须验证所有分段编号和受保护内容。验证失败时整次翻译失败，绝不输出部分结果。

### FR-06 翻译服务配置

- 设置页提供 `Base URL`、`Model`、API Key、请求超时和“测试连接”。
- 接口采用 OpenAI 兼容的 `POST /v1/chat/completions` 调用方式。
- API Key 只能存储在 Windows 凭据管理器；配置文件中不得出现 API Key 明文。
- 服务端、模型和 Key 均由用户选择。应用不内置供应商密钥或隐藏转发服务。
- 请求默认不使用流式输出，避免半成品 Markdown 被渲染。

### FR-07 剪贴板与隐私

- 工具在输入回填前保留原剪贴板内容；粘贴完成后，若剪贴板未被其他应用修改，则恢复原内容。
- 工具必须标记自身写入的剪贴板事务，避免反向触发回答翻译。
- 默认不写入提示词、回答和翻译结果日志。
- 检测到疑似 API Key、私钥或 `.env` 内容时，工具在发送至翻译服务前要求用户确认。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 资源占用 | 常驻空闲时保持低 CPU 占用，不轮询剪贴板或屏幕。 |
| 响应性 | 打开输入窗和收到剪贴板通知后 100 ms 内给出界面反馈；网络耗时由用户配置的服务决定。 |
| 稳定性 | 单次翻译异常不得导致常驻监听或 Codex 交互失效。 |
| 安全性 | API Key 使用操作系统凭据存储；Markdown 渲染必须禁用或净化不可信 HTML。 |
| 兼容性 | 支持 Windows 10/11 的常见 DPI 缩放；支持 Codex Desktop 窗口恢复和重启。 |
| 可用性 | 全部快捷键均可配置，并在冲突时提示用户。 |

## 8. 失败状态

| 场景 | 用户可见行为 |
| --- | --- |
| 未配置翻译服务 | 打开设置页，说明需要配置兼容 API。 |
| 目标不是 Codex Desktop | 不打开输入窗，显示简短通知。 |
| Codex 窗口已关闭或失效 | 英文结果保留在输入窗中，提供复制按钮。 |
| 网络超时或接口错误 | 保留原始输入，展示可读错误与重试按钮。 |
| 返回内容无法校验 | 拒绝渲染，提示“格式保护校验失败”，可重试。 |
| 剪贴板被占用 | 自动短暂重试；仍失败时显示通知，不影响 Codex。 |

## 9. 验收标准

1. 在 Codex Desktop 前台按 `Ctrl+Alt+I` 后，用户可以输入中文并通过 `Ctrl+Enter` 将英文粘贴到 Codex 输入框，且不会自动发送。
2. 在其他应用前台按相同快捷键时，应用不会向该应用粘贴文本。
3. 在 Codex 中复制含标题、列表、代码块、链接、表格和公式的回答后，中文结果窗自动出现并正确渲染。
4. 测试样本中的代码块、公式、URL、路径、命令和配置内容在翻译前后逐字一致。
5. 工具写入英文提示词后，不会立即触发一条英文到中文的自动翻译。
6. API Key 不存在于配置文件、应用日志或错误提示中。
7. API 不可用时，应用不会丢失用户正在输入的中文，也不会在 Codex 中粘贴残缺内容。

## 10. 后续版本方向

- 可选的英文提示词优化模式。
- 项目级术语表和用户确认的翻译记忆。
- Claude Code、Codex CLI 等目标适配器。
- 可选翻译历史和本地加密存储。
- 本地或企业内部翻译服务支持。
